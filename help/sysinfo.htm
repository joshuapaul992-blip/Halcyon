System Information

System Information shows what is inside your computer and how Halcyon is using it: the processor and memory, display adapters, disks and volumes, storage and USB controllers, keyboards and mice, network adapters and sound devices. It is the place to look when you want to know whether Halcyon found a piece of hardware. Open it from the desktop or the Start menu.

Finding your way

  • The tree on the left groups the devices by kind. Click a book to open it.
  • Click a device to see its details on the right: its driver, how it is connected, and what it is doing (a disk's size, a network adapter's link speed, a sound card's outputs...).
  • Computer > Interrupts shows how each device signals the processor and how often: useful when a device does not respond.
  • Kernel Log... shows the system's messages since it started; see The boot log.
  • Refresh reads everything again, for example after plugging something in.

If a device you have is missing from the list, Halcyon has no driver for it yet. Please report it, with your boot log.

NVIDIA graphics cards

On a computer with an NVIDIA graphics card (the GeForce 256 and GeForce2 up to the GeForce 10 series) System Information has an NVIDIA graphics book: the card's name, its chip and family, the video memory, the version of its video BIOS and the PCI Express link. Below the card, every connector on its back (DisplayPort, HDMI, DVI, VGA) with the monitor plugged into it: the monitor's name and its native resolution, read from the monitor itself. Newer cards (GeForce 16, RTX) are named but not looked at further yet.

Halcyon still draws on these cards through the frame buffer the firmware set up; changing the resolution at once, several monitors and a hardware pointer come with the native driver. To help write it, type NVREPORT in the Command Prompt: it saves a report, the video BIOS and the monitors' EDIDs in C:\HALCYON\NVREPORT (the screen flickers grey for a second while it measures how fast it can be drawn). Please send that folder back; its README.TXT says what is in it. The files describe the card and the monitors only.

If starting Halcyon misbehaves on an NVIDIA card, add the line nv.disable=1 to \HALCYON\SETTINGS.INI, or start in Safe Mode (F8), and send your boot log.
