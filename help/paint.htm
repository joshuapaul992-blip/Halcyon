Paint

Paint is a simple drawing program. Use it to doodle, touch up a picture, or make a quick sketch to explain something. Start it from the desktop or the Start menu; double-clicking a .bmp picture opens it in Paint.

The tools

Pick a tool from the tool box on the left, then draw on the picture:

PencilThin freehand lines, one pixel wide.
BrushThicker freehand strokes.
EraserPaints with the secondary colour, which is white unless you change it.
LineDrag from one end of the line to the other.
RectangleDrag from one corner to the opposite corner; there is an outline and a filled version.
EllipseDrag out the box the ellipse should fit in.
FillClick an area to fill it, up to its edges, with a colour.
Colour pickerClick the picture to take the colour under the pointer.

Colours

The palette at the bottom offers 28 colours. Click a colour with the left button to make it the primary colour, and with the right button to make it the secondary colour. When you draw, the left mouse button uses the primary colour and the right button the secondary one. Edit > Swap colours exchanges the two.

Undo

Paint remembers one step: Edit > Undo (Ctrl+Z) takes back your last stroke, and pressing it again brings the stroke back. Edit > Clear image starts again with a blank picture.

Opening and saving pictures

Paint opens and saves Windows bitmap files (.bmp), the kind Paint on Windows XP uses too. Use File > Save (Ctrl+S) or Save As...; if you close Paint with unsaved changes, it asks whether to save them. When the picture is bigger than the window, use the scroll bars to move around it.
