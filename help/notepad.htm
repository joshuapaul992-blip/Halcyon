Notepad

Notepad is a simple editor for plain text: notes, lists, settings files like SETTINGS.INI, or the occasional letter. It opens when you double-click a text file (.txt, .ini, .log and many more), and you can start it from the desktop or the Start menu.

Notepad handles text in any of Halcyon's keyboard layouts and files of up to 16 MB, and stays quick even with large files.

Undo and redo

Made a mistake? Press Ctrl+Z (or choose Edit > Undo) to take back your last change. Notepad remembers many changes, so you can keep pressing Ctrl+Z to go further back. Changed your mind again? Press Ctrl+Y (Edit > Redo) to put the change back.

  • Typing is undone a word at a time. A pause in your typing, a new line or moving the cursor also starts a new step.
  • Cutting, pasting, deleting a selection, Replace All and inserting the time and date are each undone in one step.
  • Undo also puts back the selection you had, so you can see exactly what changed.
  • If you undo all the way back to the moment you last saved, the asterisk (*) disappears from the title bar: the text is the same as the file again.
Note Notepad keeps about 4 MB of changes for undo. With very large edits the oldest steps are forgotten first, but your latest change can always be undone.

Word wrap

Long lines normally run off the right edge of the window and you scroll sideways to read them. Choose Format > Word Wrap to fit the lines to the window instead: Notepad breaks them between words (a very long word is broken wherever it has to be). Resize the window and the text flows again.

Word wrap only changes how the text is shown. The file itself keeps its long lines when you save it. While word wrap is on, the horizontal scroll bar is hidden because nothing needs scrolling sideways.

Notepad remembers whether word wrap is on, even after you restart the computer.

Choosing a font

Choose Format > Font... to pick the font Notepad uses. The sample shows what it looks like before you click OK. The monospace font, where every letter is the same width, is best for lists and settings files; the sans serif fonts are easier on the eye for longer text. Your choice is kept for next time.

The status bar

The status bar at the bottom shows the size of the file, the number of lines, whether the file uses Windows line endings (CR/LF), and where the cursor is: Ln is the line and Col the column. With word wrap on, a long line that is shown on several rows still counts as one line, so the numbers always match the file. Turn the status bar off and on with View > Status Bar.

Finding and replacing text

  • Edit > Find... (Ctrl+F) looks for a word or phrase; F3 finds the next one. Tick Match case to tell capital letters apart.
  • Edit > Replace... (Ctrl+H) replaces the text one match at a time (Replace) or everywhere at once (Replace All).
  • Edit > Go To... (Ctrl+G) jumps to a line number.

Handy keys

Ctrl+ASelect all the text
Ctrl+X, Ctrl+C, Ctrl+VCut, copy and paste
Ctrl+Left, Ctrl+RightMove a word at a time
Ctrl+BackspaceDelete the word before the cursor
Home, EndStart and end of the row (press Home twice to skip the indentation)
Ctrl+Home, Ctrl+EndStart and end of the file
F5Insert the time and date
F1Open this page

When you press Enter, the new line starts with the same indentation as the one before.

Saving and line endings

File > Save (Ctrl+S) saves your work; Save As... saves a copy under another name. If you type a name without an extension, Notepad adds .txt. Files are saved with Windows line endings (CR/LF), so they open nicely on Windows too; a file that came with Unix line endings keeps them. If you try to close Notepad with unsaved changes, it asks whether to save them first.
