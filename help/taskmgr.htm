Task Manager

Task Manager shows the programs that are running, how busy the processor is and how much memory is in use. Its best-known job is ending a program that has stopped responding. Press Ctrl+Alt+Del to open it at any time, or choose it from the Start menu.

What you see

  • The list of running programs, with how much memory and processor time each has used. The System entry is Halcyon itself.
  • A graph of how busy the processor has been over the last minute, and the memory in use.

Ending a program

  1. Select the program in the list.
  2. Click End Process.
  3. Halcyon asks whether you really want to end it. Click Yes.

Anything you had not saved in that program is lost, so try waiting a little first: a program may just be busy with a big job. Ending a program never affects the others, and the System entry cannot be ended.

Why does Halcyon ask? A program may only end the programs it started itself. When another program (Task Manager included) wants to end one, Halcyon asks you, so no program can quietly close your work.

Refresh updates the list straight away; it also refreshes by itself every second.
