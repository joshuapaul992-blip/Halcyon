Command Prompt

The Command Prompt is a window where you type commands instead of clicking. It feels like the DOS prompt of old Windows versions. Open it from the desktop or the Start menu, or right-click a folder in Explorer and choose Command Prompt Here to start in that folder.

Type a command and press Enter. Commands are not case sensitive: dir and DIR are the same. Type HELP to see them all.

Files and folders

DIR [path] [/W]Lists a folder (/W: names only, in columns).
CD [path]Changes to another folder; CD .. goes up one. E: switches to drive E.
TREE [path]Shows the folders below a folder as a tree.
TYPE fileShows a text file (HEXDUMP file shows any file byte by byte).
COPY from toCopies files or folders; MOVE moves them.
DEL fileDeletes files; * and ? match several names.
REN old newRenames a file or folder.
MD dir, RD [/S] dirMakes or removes a folder (/S: with everything in it).
START fileOpens a file with its program, as a double-click does.

Your computer

VOL, DRIVES, DISKSDrives, volumes and disks.
MEMMemory in use.
LSUSB, LSPCIUSB devices and PCI devices.
IRQInterrupts, the timer and how busy the processor is.
DMESG [n]The last messages of the system log; see The boot log.
DATE, TIME, VERThe date, the time and the Halcyon version.
TASKLIST, TASKKILLRunning programs, and ending one.
FORMATFormats a drive; see Formatting a disk.
KEYBOARDLists and switches keyboard layouts.
DISPLAYOpens Display Properties.
SYNC, REBOOT, SHUTDOWNWrites everything to the disks; restarts; turns off.

Running programs

Type the name of any program in C:\PROGRAMS to run it, for example NOTEPAD readme.txt, PAINT or CALC. Programs that write text, such as PING, IPCONFIG and NSLOOKUP (see Network tools), show it in the Command Prompt window. EXPLORER [folder] opens a folder.

Saving a command's output

Add > file to a command to write what it prints to a file, or >> file to add it to the end of a file. For example DIR C:\Documents > list.txt. ECHO text > file writes a line of your own, CLS clears the window and COLOR 0A changes its colours.
