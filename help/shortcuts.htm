Keyboard shortcuts

You can do a lot without reaching for the mouse. Here are the keys that work everywhere in Halcyon, followed by the ones most programs understand.

Anywhere

Windows key or Ctrl+EscOpen or close the Start menu
Alt+TabSwitch to the next window
Alt+F4Close the window in front
Ctrl+Alt+DelOpen Task Manager
Alt or F10Open the window's menu bar
Left Alt+ShiftSwitch to the next keyboard layout
F1Help for the program you are using
Volume keysChange the volume or mute the sound (on keyboards that have them)

In most programs

Ctrl+N, Ctrl+O, Ctrl+SNew, Open, Save
Ctrl+X, Ctrl+C, Ctrl+VCut, Copy, Paste
Ctrl+Z, Ctrl+YUndo, Redo
Ctrl+ASelect everything
Ctrl+F, F3Find, Find Next
Tab, Shift+TabMove between the parts of a dialog
Enter, EscOK and Cancel in a dialog

In Explorer

EnterOpen the selected item
BackspaceUp one folder
Alt+LeftBack
F2Rename
DeleteMove to the Recycle Bin (Shift+Delete deletes for good)
F5Refresh

In Help and Support

Alt+Left, Alt+RightBack and Forward
Alt+HomeThe home page
Alt+C, Alt+N, Alt+SThe Contents, Index and Search tabs
