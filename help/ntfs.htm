NTFS drives and Windows

NTFS is the file system Windows uses for its own disks, and many external hard disks come formatted with it too. Halcyon can read and write NTFS drives. Because these drives often belong to Windows, Halcyon is careful with them: if there is any chance that writing could confuse Windows, it opens the drive read-only and tells you why. You can still open and copy every file.

Why is my drive read-only?

Right-click the drive in My Computer and choose Properties. The reason is written there. The common ones are explained below.

"Windows did not shut down completely"

Windows 8, 10 and 11 normally do not really shut down: with Fast Startup they hibernate instead, so they start faster next time. The Windows drive is then still "in use" by the sleeping Windows, and changing it from another system could lose your work. Halcyon leaves such a drive alone.

To let Halcyon write to it, do one of these in Windows:

  • Hold Shift while you click Shut down. This shuts Windows down completely, just this once.
  • Choose Restart instead of Shut down, and start Halcyon from the restart. A restart always shuts Windows down completely.
  • Turn Fast Startup off for good: in Windows, open Control Panel > Power Options > Choose what the power buttons do, click Change settings that are currently unavailable and untick Turn on fast startup.

The same applies after you have used Hibernate in Windows.

"The drive needs to be checked"

Windows marks a drive when it was not unplugged or shut down properly, or when it found a problem. Start Windows and let it check the drive (or run chkdsk), then try again in Halcyon.

"This is an internal Windows drive"

The disk inside your computer that Windows starts from is opened read-only even when Windows shut down properly, so that you never change it by accident. If you do want to write to it, open the drive's Properties and tick Allow Halcyon to write to this drive. Halcyon remembers this for that drive; untick it to make the drive read-only again.

Good habits

  • Use Safely remove USB storage (or turn Halcyon off) before you unplug an external NTFS disk; otherwise Windows checks it at its next start.
  • Some files are shown but cannot be opened: files encrypted by Windows, files Windows compressed with its newer compression, and shortcuts that point elsewhere on the disk (symbolic links and junctions).
