Drives, USB sticks and CDs

Open My Computer to see every drive Halcyon can use. Each drive has a letter, just as on Windows: C: is the drive Halcyon started from; hard disks, USB sticks, memory cards and CD drives get the next free letters.

USB sticks and memory cards

Plug in a USB stick and it appears in My Computer after a moment, with a balloon in the corner of the screen. Before you pull it out again, click the USB icon in the notification area and choose Safely remove USB storage: Halcyon finishes writing everything to the stick and then tells you it is safe to remove it. Pulling a stick out while files are still being written can damage them.

CDs and DVDs

CD and DVD drives show the disc's name when a disc is in. Discs are read only. To take a disc out, right-click the drive in My Computer and choose Eject. Halcyon notices when you put in another disc.

Drive properties

Right-click a drive and choose Properties to see its label, its file system, how big it is and how much space is free. A padlock on a drive's icon means it is read-only: you can open files on it but not change them. The Properties dialog explains why, for example a write-protected memory card, a CD, or a Windows drive that Windows did not shut down completely.

File systems

Halcyon reads and writes the file systems most disks use:

  • FAT12, FAT16 and FAT32: floppies, older and smaller USB sticks and memory cards.
  • exFAT: most USB sticks and SD cards larger than 32 GB.
  • NTFS: Windows drives and many external disks. See NTFS drives and Windows.
  • ISO 9660 with long names: CDs and DVDs (read only).

To start afresh with an empty drive, see Formatting a disk.
