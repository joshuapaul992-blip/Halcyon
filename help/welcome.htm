Welcome to Help and Support

Hello, and welcome to Halcyon! These pages explain how to get around your computer, use the programs that come with Halcyon, and fix things when they go wrong. Pick a topic below, or use the Index and Search tabs on the left to find something quickly.

New to Halcyon? Start with Getting started with Halcyon. It takes about five minutes and covers everything you need for your first day.

Programs that come with Halcyon

Notepad · Paint · Calculator · Media Player · Web Browser · Command Prompt · Task Manager · System Information · Sonar

Did you know?

You can press F1 in almost any Halcyon program to open its help page straight away. Try it in Notepad or Paint!

Halcyon is a hobby operating system and is still being written. Some features described here are new; if something does not work the way this help says, please report it together with your boot log.
