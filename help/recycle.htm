The Recycle Bin

Deleted something by mistake? Don't worry. When you delete files or folders from your hard disk, Halcyon does not throw them away straight away: it puts them in the Recycle Bin. They stay there until you empty it, so you can always change your mind.

The Recycle Bin is on the desktop. Its icon shows paper inside when it holds something, and an empty basket when it does not.

Getting a file back

  1. Double-click the Recycle Bin on the desktop. It lists each deleted item with the folder it came from and the date it was deleted.
  2. Select the items you want back (you can select several).
  3. Choose Restore. The items go back to the folders they came from.

Emptying the Recycle Bin

Deleted files still take up space on the disk. When you are sure you no longer need them, right-click the Recycle Bin and choose Empty Recycle Bin. Halcyon asks you to confirm, then deletes them for good. To remove just one item for good, select it in the Recycle Bin and press Delete.

When files are deleted straight away

  • Holding Shift while you delete (Shift+Delete) skips the Recycle Bin.
  • Files on USB sticks, memory cards and other removable drives are deleted straight away, as on Windows: the stick could be taken to another computer before you emptied the bin. (The drive Halcyon itself started from keeps its Recycle Bin, even when that is a USB stick.)
  • Drives that Halcyon may only read, such as a Windows disk that was not shut down cleanly, cannot have anything deleted; Explorer says why.

Halcyon asks first, because these files cannot be brought back.

How big the Recycle Bin can get

Each drive's Recycle Bin may use up to a tenth of the drive. When it is full, the oldest deleted items are removed for good to make room. To change the limit, right-click the Recycle Bin, choose Properties and set the size for each drive.

How it works Each drive keeps its own hidden recycle folder, so deleting a file never has to copy it to another drive. Halcyon notes where the file came from and when it was deleted, so Restore can put it back.
