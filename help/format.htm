Formatting a disk

Warning Formatting erases everything on the drive. Copy anything you want to keep somewhere else first.

Formatting prepares a drive with a fresh, empty file system. You might do it to clean out an old USB stick, or to use a stick on another kind of computer.

How to format a drive

  1. Open My Computer.
  2. Right-click the drive and choose Format....
  3. Choose the file system, the allocation unit size and a label (see below).
  4. Click Start, read the warning, and click OK if you are sure.

Halcyon does a quick format: it writes a new, empty file system without checking every sector of the disk, so it takes only a few seconds. Halcyon will not format the drive it is running from.

Which settings should I choose?

  • File system: Halcyon suggests the same one Windows would. FAT32 works almost everywhere (but holds no file over 4 GB); exFAT suits large sticks and cards and big files; NTFS is what Windows uses for its own disks. FAT12 and FAT16 are for very small or very old media.
  • Allocation unit size: leave it on the default unless you know you need something else. Larger units can be a little faster for big files but waste space with many small ones.
  • Volume label: a name for the drive, shown in My Computer.

Formatting from the Command Prompt

The FORMAT command does the same job. For example FORMAT E: /FS:NTFS formats drive E: with NTFS. Type FORMAT on its own to see the options. See Command Prompt.
