Web Browser

The Web Browser shows pages from the Web and web pages stored on your computer. Start it from the desktop or the Start menu. You need a network connection for the Web; see Connecting to a network.

Going places

  • Type an address such as example.com in the Address bar and press Enter (or click Go). Ctrl+L or F6 takes you to the address bar.
  • Click a link to follow it; the status bar shows where a link leads when you point at it.
  • Back and Forward (Alt+Left, Alt+Right) move through the pages you have visited; Reload (F5) loads the page again and Stop (Esc) stops loading.
  • Home shows the start page.

The Web Browser also opens files on your computer: type a path such as C:\Documents\Web, where you will find some sample pages to try. Double-clicking an .htm file opens it here too.

Secure sites

Addresses that start with https:// are encrypted. The Web Browser checks the site's certificate against a list of trusted authorities, and the status bar says Secure when it checked out. If a certificate is expired, issued for another site, or not from a trusted authority, the browser shows an error page explaining the problem instead of the page: it is there to protect you, and there is no way around it.

Saving and looking closer

File > Save Page As... saves the page to a file, and View > Page Source shows its HTML as plain text. Right-click a link to open it, copy its address or save what it points to.

What the Web Browser cannot do yet

It is a small browser. It shows text, headings, lists, tables, forms and PNG, GIF and BMP pictures, but it does not run JavaScript, has very little style sheet support, and cannot show JPEG pictures or videos. Some sites need a newer encryption method (TLS 1.3) than it has; those show an error page.
