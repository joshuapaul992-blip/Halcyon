Display Properties

Display Properties sets the screen resolution and the screen saver. Open it from the Control Panel (Display...), by right-clicking the desktop and choosing Properties, or by typing DISPLAY in the Command Prompt.

Screen resolution

The resolution is how many dots (pixels) the screen shows: more dots fit more on the screen, but make everything smaller. When Halcyon starts for the first time it asks the monitor which resolution suits it best and uses that. To pick another one, choose it in the Screen resolution list and click Apply.

  • On computers where Halcyon can switch straight away (such as virtual machines), the screen changes at once and Halcyon asks "Do you want to keep these settings?". If you do not answer within 15 seconds (perhaps because the screen went black), it goes back to the old resolution by itself.
  • On most real PCs Halcyon cannot change the resolution while it is running yet. It saves your choice and uses it the next time Halcyon starts.
Screen stays black after a restart? Restart, press F8 when the "Advanced Startup Options" prompt appears, and choose Safe video mode (800 x 600). Then pick a resolution your monitor can show. See Solving startup problems.

Screen saver

The Screen Saver tab chooses a moving picture that appears when you have not used the computer for a while. See Screen savers.
