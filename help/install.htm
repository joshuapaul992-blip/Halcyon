Installing Halcyon on a computer

Halcyon runs straight from a USB stick or a CD, so you can try it without changing anything on your computer. When you are ready, you can install it on the computer's own disk: it then starts faster and you no longer need the stick.

Starting the installer

Choose Start > Install Halcyon. When Halcyon starts from a USB stick or a CD, it also offers to install itself. The installer works with the SATA and NVMe disks inside your computer.

Where to install

The installer lists the disks it found, with their size and what is on them. You choose one of two ways:

  • Use the whole disk. Everything on the disk is erased. Because this cannot be undone, the installer asks you to confirm and names the disk, its size and what is on it, so you can be sure it is the right one.
  • Use the free space. Halcyon goes into the unused space next to the partitions that are already there. Existing partitions are never made smaller and nothing on them is touched.
Before you start Back up anything important. Installing an operating system always carries some risk, and Halcyon is still young.

What the installer does

  1. It prepares the disk the way your computer starts: with a GPT partition table and an EFI system partition on newer (UEFI) computers, or with an MBR partition table and an active FAT32 partition on older (BIOS) computers. Where the layout allows, the disk can start both ways.
  2. It copies Halcyon's start-up code, the system, the programs, the system sounds and the sample documents, and then checks that every file arrived intact.
  3. It brings your settings from the stick along, so the installed Halcyon looks and works the way you set it up.

When it has finished, remove the stick and restart.

Installing next to Windows

Windows keeps working. Its start-up files are left in place, and you choose between Windows and Halcyon in your computer's boot menu when it starts (the key for the boot menu is often F12, F11, F8 or Esc; your computer usually shows it briefly when it starts). From Halcyon you can open the Windows drive: see NTFS drives and Windows, and turn Windows' Fast Startup off if you want to change files on it.

If there is no free space next to Windows, you can make some in Windows with Disk Management ("Shrink Volume") before you install Halcyon.
