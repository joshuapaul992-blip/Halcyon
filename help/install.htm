Installing Halcyon on a computer

Halcyon runs straight from a USB stick, so you can try it without changing anything on your computer. When you are ready, Halcyon Setup installs it on a disk inside the computer: it then starts without the stick.

Before you start Back up anything important. Installing an operating system always carries some risk, and Halcyon is still young.

Starting Setup

Choose Start > Install Halcyon. When Halcyon starts from a USB stick, the Welcome to Halcyon window also offers it: click Install Halcyon..., or Not now. Check Don't show this again if you do not want to be asked at every start. Setup installs on the SATA and NVMe disks inside the computer, never on the stick Halcyon runs from. Press F1 in Setup to open this page.

The steps

  1. Welcome to the Halcyon Setup Wizard. Click Next >.
  2. Choose a disk. Every internal disk is listed with its name and size. Below the list you see what is on the selected disk: its partitions with their file systems, labels, drive letters and sizes, the free (unpartitioned) space, and whether Windows is installed on it. A disk that cannot be used says why.
  3. Where to install. Choose one of:
    • Use the whole disk. Everything on the disk is erased and Halcyon gets all of it.
    • Install in the free space. Halcyon goes into the unpartitioned space next to the partitions that are already there. They are never made smaller, moved or changed. This needs at least 128 MB of free space; when it is not possible, Setup tells you why.
  4. Ready to install. A summary: the disk, what happens to it, how Halcyon will start, and how many files are copied. Click Install. If you chose the whole disk, Setup first asks whether you are sure, naming the disk and what is on it; the answer is No unless you click Yes.
  5. Installing Halcyon. Setup creates the partition, formats it (FAT32), writes the boot code, copies the files, and then checks every copied file against the original. You cannot cancel at this point.
  6. Completing the Halcyon Setup Wizard. Remove the USB stick and click Restart, or Close to keep working from the stick.

Use < Back to change an earlier choice and Cancel to stop before anything is written.

How the disk starts

On newer (UEFI) computers Setup makes a GPT partition table with an EFI system partition for Halcyon and adds Halcyon to the computer's boot menu. On older (BIOS) computers it makes an MBR partition table with an active FAT32 partition. Where the layout allows, the disk starts both ways. Your settings, the programs, the system sounds, these help pages and the documents on the stick are copied along.

Installing next to Windows

Windows keeps working, and Setup never writes to its partitions or its start-up files.

  • On a UEFI computer, Halcyon becomes the first entry of the firmware's boot menu; choose Windows Boot Manager there to start Windows (the key for the boot menu is often F12, F11, F8 or Esc; the computer usually shows it briefly when it starts).
  • On a BIOS computer, a menu appears when the computer starts: Please select the operating system to start, with Halcyon and Windows. Use the arrow keys and Enter; after 10 seconds Halcyon starts (boot.timeout in SETTINGS.INI changes the wait).

If there is no free space next to Windows, make some in Windows with Disk Management ("Shrink Volume") before you run Setup. From Halcyon you can open the Windows drive: see NTFS drives and Windows.
