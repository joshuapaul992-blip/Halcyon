Solving startup problems

Most computers start Halcyon without any fuss. If yours does not, this page helps you find out why, and how to get going anyway.

The computer does not start from the USB stick

  • Choose the stick in your computer's boot menu (often F12, F11, F8 or Esc just after you switch on).
  • On newer computers, turn Secure Boot off in the firmware settings: Halcyon's start-up program is not signed by Microsoft, and Secure Boot refuses to run it.
  • Write the stick again with a "raw" or "DD image" writer, such as Rufus in DD image mode. Copying the image file onto the stick like an ordinary file does not work.

Advanced Startup Options (F8)

While Halcyon starts, it shows Press F8 for Advanced Startup Options for a moment. Press F8 then to see a menu. Use the arrow keys and Enter:

Start Halcyon normallyAs if you had not pressed F8.
Safe ModeStarts with as little as possible: no USB, SATA or NVMe drivers and no interrupts, and with the system's messages on screen. Use it to see how far Halcyon gets.
Start with the options belowStarts with the switches you ticked in the rest of the list.
Verbose bootShows the system's messages on screen while it starts.
Disable USB 3.x / USB 2.0 / USB 1.1 controllersLeaves out a kind of USB controller. Try these when Halcyon stops while it looks for USB devices.
Disable SATA controllers, Disable NVMe controllersLeaves out the disk drivers.
Disable ACPIDoes not read the firmware's description of the hardware.
Disable interruptsPolls every device instead. Slow and power-hungry, but it works around broken interrupt routing.
Disable MSI, Use the legacy PICOlder ways of delivering interrupts, for unusual hardware.
Safe video mode (800 x 600)For a screen that stays black or shows a garbled picture.

A good way to narrow down a problem is to switch one thing off at a time. When you have found the switch that helps, please report it, with your boot log.

Halcyon starts, but something does not work

  • A device is missing: look in System Information.
  • A drive is read-only: see NTFS drives and Windows and Drive properties.
  • No network or no sound: see Connecting to a network and Sounds and Audio Devices.
  • A program hangs or closes: see When a program stops responding.
