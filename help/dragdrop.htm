Moving files with drag and drop

Instead of copying and pasting, you can pick files up with the mouse and drop them where they should go: into another folder, another Explorer window, onto the desktop or into the Recycle Bin.

How to drag

  1. Point at a file (or a selection of files).
  2. Hold down the left mouse button and move the mouse. The pointer shows what will happen when you let go.
  3. Move over the folder, window or icon where the files should go, and release the button.

Press Esc while dragging to change your mind.

Tip: drag with the right mouse button instead, and when you let go Halcyon asks: Copy Here, Move Here or Cancel.

Copy or move?

Halcyon guesses what you mean, just like Windows does:

  • Dropping on another folder of the same drive moves the files.
  • Dropping on another drive, such as a USB stick, copies them, so the originals stay where they were.
  • Hold Ctrl while you drop to always copy, or Shift to always move.
  • Dropping on the Recycle Bin deletes the files (you can still get them back from there).
  • If a file with the same name is already there, Halcyon asks whether to replace it.

Dropping files on programs

Drag a text file onto an open Notepad window, a picture onto Paint or a sound onto Media Player to open it there.
