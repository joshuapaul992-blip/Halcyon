Connecting to a network

Halcyon connects to your home or office network, and through it to the Internet, with a network cable. Plug the cable into the computer and into your router, and in most homes that is all: Halcyon gets an address from the router by itself (this is called DHCP) and you can start the Web Browser.

The network icon next to the clock shows whether you are connected. Point at it to see the address you got; click it to open Network Connections.

Network Connections

Open it from the network icon, the Start menu or the Control Panel (Network...). For each network adapter it shows:

  • whether the cable is connected and how fast the link is,
  • the computer's address, the router (gateway) and the DNS servers that turn names like example.com into addresses,
  • how long the address from DHCP lasts, and how much data has gone in and out.

Setting an address by hand

Some networks have no DHCP server, or need a fixed address. Untick Obtain an IP address automatically (DHCP), type the address, the subnet mask and the gateway, and click OK. In the same way you can type your own DNS servers instead of using those from DHCP: untick Obtain DNS server addresses automatically and fill in the preferred and alternate server. Changes take effect at once and are kept for next time. Ask whoever runs the network which numbers to use.

Not connected?

  1. Check the cable at both ends. The lights next to the socket should be on.
  2. Open Network Connections. If it says the cable is unplugged, try another cable or another socket on the router.
  3. If you have a link but no address, click Renew (or type ipconfig /renew in the Command Prompt) to ask the router again.
  4. If names do not work but addresses do (see PING), check the DNS servers.
  5. If your adapter is not listed at all, Halcyon has no driver for it yet. Halcyon knows the usual Intel and Realtek wired adapters and those of virtual machines.
Wi-Fi Halcyon does not support wireless networks yet, so please use a network cable.
