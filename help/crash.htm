When a program stops responding

Every program in Halcyon runs in its own protected space. If one gets stuck or crashes, the rest of the system keeps going: the desktop, the other programs and your files are safe.

A program is stuck

A program that is busy may stop redrawing its window or answering clicks. Give it a moment first; it may be working on something big. If it stays stuck:

  • Click its close button. If the program does not answer, click it again after a few seconds: Halcyon then says the program is not responding and offers to end it.
  • Or press Ctrl+Alt+Del to open Task Manager, select the program and click End Process.

Anything you had not saved in that program is lost.

"... has encountered a problem and needs to close"

This message means the program did something it was not allowed to do, and Halcyon stopped it before it could cause harm. Click to close the message and start the program again. If it happens again and again with the same file or the same steps, please report it, with your boot log.

If the whole system stops

Very rarely, Halcyon itself runs into a problem it cannot handle and shows a screen with technical details. Note what you were doing, restart the computer and send the boot log with your report: Halcyon saves it after a crash. If it happens every time you start, see Solving startup problems.
