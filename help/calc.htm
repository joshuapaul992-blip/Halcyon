Calculator

Calculator works like a pocket calculator. Click the buttons, or just type: the number keys, + - * / and Enter (or =) all work. Start it from the Start menu, or with the calculator key if your keyboard has one.

Doing a sum

Type the first number, an operator, the second number and =. The result appears straight away; the line above it shows the calculation so far. Calculator works out each step as you go, just like a pocket calculator, so 2 + 3 * 4 = gives 20, not 14.

The buttons

CClears everything and starts again.
CEClears just the number you are typing.
Backspace arrowRemoves the last digit (Backspace).
±Changes the sign of the number.
Square root, %, 1/xSquare root, percent and the reciprocal (one divided by the number) of the number shown.

The memory

The top row keeps one number for later: MS stores the number shown, MR brings it back, M+ and M- add the number shown to it or take it away, and MC clears the memory.

Copying numbers

Copy (Ctrl+C) copies the result so you can paste it into another program; Paste (Ctrl+V) types a copied number into Calculator. Press F1 for this page; the Help button shows what Calculator can do.
