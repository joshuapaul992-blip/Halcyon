Files and folders in Explorer

Explorer is the window you get when you open My Computer, My Documents or any folder. It shows what is in a folder and lets you open, copy, move, rename and delete things.

Finding your way

  • My Computer shows your drives. Double-click a drive to see what is on it.
  • Double-click a folder to open it. Back (Alt+Left) returns to where you were, and Go > Up One Level (Backspace) goes to the folder that holds this one.
  • The address bar shows where you are. You can type a path there, such as C:\Documents, and press Enter.
  • The View menu switches between large Icons and a Details list with sizes and dates. View > Refresh (F5) reads the folder again.
  • The task pane on the left offers the most common jobs for whatever you have selected.
  • Start typing a name to jump to the first file that begins with those letters.

Opening files

Double-click a file (or select it and press Enter) to open it in its program: text files in Notepad, pictures (.bmp) in Paint, sounds (.wav) in Media Player, web pages (.htm) in the Web Browser, and programs (.exe) run. For anything else, Halcyon offers to open the file in Notepad.

Copying and moving

Select a file or folder, choose Copy (Ctrl+C) or Cut (Ctrl+X), open the folder where it should go, and choose Paste (Ctrl+V). Copy leaves the original where it is; Cut moves it. Large copies run in the background with a progress window and a Cancel button, so you can keep working. You can also drag files where you want them, and work on several files at once.

Deleting

Select what you want to delete and press Delete (or right-click it and choose Delete). Files deleted from your hard disk go to the Recycle Bin, so you can get them back if you change your mind. Files on USB sticks and other removable drives are deleted for good, so Halcyon asks first.

Renaming

Select the item and press F2, or right-click it and choose Rename. Type the new name in the box and click OK. Names can be long and may contain spaces and letters from any language.

New folders and documents

Right-click an empty part of the folder (or open the File menu) and choose New Folder or New Text Document, then type its name. The same menu has Command Prompt Here, which opens a Command Prompt in that folder. Right-click a file for Open with Notepad, handy for files Halcyon does not know.

Properties

Right-click an item and choose Properties to see its size, where it is, and when it was created and changed. A drive's Properties show its file system, label and free space; see Drives, USB sticks and CDs.
