Network tools for the Command Prompt

When the network does not behave, these small programs help you find out where the trouble is. Type them in the Command Prompt. Unlike Halcyon's own commands, their options must be typed in lower case.

IPCONFIG: what is my address?

ipconfig shows each network adapter with its address, subnet mask and gateway. ipconfig /all adds the DNS servers, the hardware address and the DHCP details.

ipconfig /renewAsks the DHCP server for an address again.
ipconfig /releaseGives the address back.
ipconfig /flushdnsForgets the names looked up so far.
ipconfig /statsCounts of what has been sent and received.
ipconfig /connsThe connections that are open.

PING: can I reach it?

ping 192.168.1.1 or ping example.com sends four small messages and shows how long each answer took. Answers mean the other computer can be reached; "Request timed out" means it cannot (or that it does not answer pings). -n 10 sends ten, -t keeps going until you close the window.

A good order for finding a problem: ping your router (the gateway from ipconfig), then an address on the Internet, then a name. If the address works but the name does not, the trouble is with DNS.

NSLOOKUP: which address has this name?

nslookup example.com asks the DNS server for the name's address. -type=MX asks for the mail servers instead, and a server after the name asks that server, for example nslookup example.com 9.9.9.9.

WGET: fetch a file

wget https://example.com/ downloads a page or a file into the current folder; wget -O - URL shows it in the window instead.
