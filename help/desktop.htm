The desktop and the Start menu

The desktop

The desktop is your starting point. Double-click an icon to open it:

  • My Computer shows your drives: the disk Halcyon started from (C:), other disks, USB sticks and CD drives.
  • My Documents opens your own folder, C:\Documents.
  • Command Prompt, Notepad, Paint, Web Browser and System Information start those programs.
  • The Recycle Bin keeps files you have deleted until you empty it. See The Recycle Bin.

Right-click an empty part of the desktop for Refresh, Open Command Prompt here and Properties (which opens Display Properties). You can also select icons with the arrow keys and open one with Enter.

The Start menu

Click the green Start button, or press the Windows key (or Ctrl+Esc). The left column lists the programs; the right column takes you to My Documents, My Computer, the Control Panel, Network Connections, System Information, Task Manager, Help and Support (these pages) and About Halcyon. At the bottom are Restart and Turn Off. Use the mouse or the arrow keys and Enter; Esc closes the menu.

The taskbar

Each open window has a button on the taskbar. Click it to bring the window to the front; click it again to minimize the window. When many windows are open the buttons get narrower so they all fit.

The notification area

At the right end of the taskbar, next to the clock, small icons show what is going on:

SpeakerClick for a volume slider and Mute; double-click for Sounds and Audio Devices.
NetworkShows whether you are connected; click it for Network Connections.
Keyboard (EN...)Shows the keyboard layout in use; click to switch. See Keyboard and input languages.
USBAppears when USB storage is plugged in; click it and choose Safely remove USB storage before you unplug a stick.

Now and then a yellow balloon pops up above the notification area to tell you about something, such as a new USB device. It goes away by itself.
