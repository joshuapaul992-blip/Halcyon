Sample pages

These pages show what the Web Browser can display. They are plain HTML files in C:\Documents\Web; open them in Notepad to see how they are made.

  • Text: headings, paragraphs, bold and code, lists, quotations, preformatted text, rules and entities
  • Tables: borders, column widths, spans and colours
  • Images: PNG, GIF and BMP, and alternative text
  • Forms: text fields, check boxes, radio buttons, lists and buttons
  • Latin-1: a page in an older character set
  • The lists on the text page (a link to a place in a page)
  • A page that does not exist
