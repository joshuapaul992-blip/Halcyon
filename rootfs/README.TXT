Welcome to Halcyon!
===================

Halcyon is a small hobby operating system with an early-2000s style
desktop. It boots from a USB stick on both BIOS and UEFI PCs and has
its own drivers for:

  * USB 1.1 (UHCI, OHCI), USB 2.0 (EHCI) and USB 3.x (xHCI) controllers
  * USB hubs, keyboards, mice/tablets and mass storage devices
  * SATA disks through AHCI
  * FAT12, FAT16 and FAT32 file systems, read and write, long file names

Things to try
-------------
  - Double-click "My Computer" to browse your drives.
  - Plug in a USB stick: it appears as a new drive letter.
  - Open "Command Prompt" and type HELP.
  - Write something in Notepad and save it to the USB stick.
  - Draw a picture in Paint and save it as a .BMP file.

Files on this drive
-------------------
  \HALCYON\KERNEL.BIN        the kernel
  \EFI\BOOT\BOOTX64.EFI      the UEFI boot loader
  \Documents                 sample documents
